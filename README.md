# 📰 24×7.LIVE - News App

**24×7.LIVE** is a real-time, category-based news web application built with **HTML, CSS**, and **JavaScript**, using the [NewsAPI](https://newsapi.org). It lets users browse breaking and older news across topics like **General**, **Politics**, **Sports**, **Education**, **Crime**, and **Career** — all in a clean, responsive interface.

> ⚡ Built to keep you updated. Anytime. Anywhere.

---

## 🌟 Features

- 🗞️ Live news by category (Top headlines)
- 🔁 Fallback to older news if no new headlines are found
- 📅 Displays article date, day, and time
- ⏱️ Real-time live clock (updates every second)
- 📱 Responsive design for mobile and desktop

---

## 🔧 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- [NewsAPI](https://newsapi.org)
